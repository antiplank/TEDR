# The Expanse Dice Roller

A dice-rolling and churn-tracking bot for Discord.

## Commands

| Command | What it does |
| --- | --- |
| `!e` | Rolls 3d6 with a DRAMA die |
| `!e 2d10 +3 kicking down the door` | Dice, bonus, and a label — all optional |
| `!edm` | Same as `!e`, but the result is DMed to you |
| `!e help` | DMs you the full instructions |
| `!churn` | Shows your churn counter |
| `!churn 3` / `!churn -2` / `!churn reset` | Adjusts it |
| `!bobbie` / `!amos` | Images |
| `!servers` | How many servers the bot is in |
